# 显示大小与动作显示异常

## 小尺寸与颗粒感

Pets v2 的单格固定为 192 × 208 像素。上传更大的整张图片会违反格式，不能提升每一帧的分辨率。Q 版通过放大头部、五官和轮廓，减少衣服上的细碎纹样，改善小尺寸下的辨识度。

实际大小在「设置 → Pets → Customize → Pet size」调整，见 [Pets 官方说明](https://learn.chatgpt.com/docs/pets)。预览页的显示宽度滑杆用于观察不同大小；默认使用像素化缩放，与本次检查的客户端一致。“平滑参考”只改变网页预览。

## 拖动、挥手、跳跃时下半身透明消失

用户报告这一现象主要出现在拖动、挥手、跳跃期间，并进一步澄清：实际是下半身变透明、只剩上半身，而非白色矩形盖住角色。裁切范围或动作显示区域异常是待验证的假设，尚未确认根因。对当时从 Pets 下载的旧版成品重新检查，结果如下：

- 1536 × 2288、v2 格式，全部 73 个必要帧存在，15 个未用单元透明。
- 帧数为 `[6,8,8,4,5,8,6,6,6,8,8]`，与检查时客户端使用的帧数相同。
- 全部必要帧的下半部分都有角色像素，未发现空白帧、整块不透明背景或透明像素中的残留 RGB。
- 本地结构检查和 Pets 服务端预检均通过。

这些结果排除了部分素材问题，**不能证明客户端的实际播放正常，也不能证明 Q 版重绘能修复运行时故障**。消失、变白的根因尚未复现和确认。

网页预览提供“连续切换动作”，会交替播放动作和待机。可以在浅色、深色、透明网格背景下检查是否出现同样现象。若网页一直正常而 Pets 仍出现问题，请记录出现时的动作、显示大小、是否正在拖动、是否跨屏，以及异常画面。截图应只保留宠物区域，避免包含私人窗口。

本仓库只包含角色素材与网页预览；Pets 客户端的窗口合成和动画执行由宿主负责。
