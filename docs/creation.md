# 制作说明

## Q 版重绘

原版在小尺寸下细节过密。本次使用大头短身、加粗紫色轮廓、简化衣服纹样和更大五官，重新生成全套动作；没有对旧图进行锐化或插值来冒充新增细节。各标准行动画以首个落地姿势为尺度参考，整行使用相同变换，站立高度目标 180 像素、基线 201 像素；实际姿势仍保留呼吸、倾头和跳跃位移。

## 形象约束

白色长发、淡紫瞳、短象牙色龙角、小型浅紫龙翼、白色卷尾、白紫裙装。以较深紫色轮廓维持深浅背景上的可读性。使用新的简化服饰与菱形装饰，不加入原参考图的小伙伴或标志性结饰。保持脸、发型、服饰、尾巴方向和双臂数量一致。

## 实际制作顺序

1. 生成一张主形象作为后续行的主要身份参考。
2. 逐行制作九种标准动作。每次检查完整角色、帧数、肢体、间距、基线和状态语义；发现问题重绘对应源行。
3. 根据完整角色连通区域提取姿势，整行保持同一尺度，不逐帧填满画格。跳跃保留真实垂直位移。
4. 对标准行使用测量后的整行尺度与基线注册，给跳跃留出头顶空间；注册后的落地与待机基线一致。
5. 生成并人工确认正上、正右、正下、正左四个注视锚点，再分两个连贯八帧行补全顺时针注视。头与眼睛转动，身体和脚底保持锚定。
6. 先注册第一行注视，再使用同一变换合成第二行。最后对完整精灵图执行一次边缘去色溢出处理。
7. 从最终编码的精灵图渲染预览，检查格式、透明区域、动作、基线、方向语义及连续性，并进行三位独立检查员的方向盲测。
8. Pets 服务端校验确认 `valid: true` 后，再替换原有自定义宠物的素材并核对启用状态。本仓库不包含该账号的身份或临时上传信息。

这些步骤描述本次实际流程，不是可在本仓库内一键运行的完整生成器。提交的 `scripts/render.py` 只负责从最终图重新导出预览；`scripts/validate.py` 只检查明确列出的格式和几何条件。

## 重新制作的提示要点

为每个状态生成独立的水平动画行，附上固定主形象和布局参考。每行恰好生成指定帧数，角色彼此分开、全身完整且尺度一致，不加入浮动图标、速度线、影子、烟尘或文字。生成时使用可分离背景；最终上传必须是真正透明的 RGBA PNG。

| 状态 | 帧数 | 动作要点 |
| --- | ---: | --- |
| idle | 6 | 轻微呼吸与眨眼，双脚稳定 |
| running-right | 8 | 向屏幕右侧，肢体交替迈步 |
| running-left | 8 | 逐帧镜像已验收的右行动画，保持时间顺序；Q 版服饰无左右限定标记或手持物 |
| waving | 4 | 一只手抬起、轻摆、收回，恰好两只手臂 |
| jumping | 5 | 蓄力、离地、顶点、下降、落地 |
| failed | 8 | 低头、失落、缓慢恢复，无浮动符号 |
| waiting | 6 | 双手胸前，略前倾，期待输入 |
| running | 6 | 原地思考，手托下巴、眼神移动，不是跑步 |
| review | 6 | 扫视检查、倾头、轻轻点头 |
| look-a | 8 | 000 → 157.5°，从上方经过屏幕右侧 |
| look-b | 8 | 180 → 337.5°，从下方经过屏幕左侧 |

任何重绘都必须重新检查身份、肢体、透明边缘、方向及播放连续性。不要仅凭校验器成功就认定美术质量合格。
