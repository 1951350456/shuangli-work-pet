# D 版制作与验收

用户选择四款静态概念图中的 D 方案，随后要求鼠标悬浮互动的跳跃张开双臂、微笑迎接抱抱。以该 D 原图作为主形象，采用粗深紫轮廓、白色与淡紫色大色块，减少微小衣纹与链饰，保留双角、龙翼、结形发饰、双腰饰和卷尾。

九个动作分别通过内置 image_gen 生成。左右移动各自生成，避免镜像改变发饰和尾巴的物理位置。跳跃五帧包括张臂准备、离地、快乐抱抱顶点、下降、落地；没有用位移后处理伪造起跳。实测离地 31 px，落地与待机基线差 0 px。

使用技能附带脚本提取完整连通姿势并检查。以每行首个完整站立姿势为比例基准，在所有动作的实际外沿约束下有限枚举公共整数高度与基线，选出最大的共同高度 183 px、基线 203 px。整行只用一个缩放和位移，保留同一行的呼吸、步态与跳跃变化，不逐帧缩放居中。角色轮廓留有安全边界。

先验收九行动作，再生成并批准上、右、下、左四个注视锚点；两个八帧注视行顺序生成，第二行与第一行共用注册尺度。最终进行一次绿色色键边缘清理，再通过完整图集结构、透明度、方向语义、连续性、三名隔离检查员的盲审与 Pets 服务端预检。最终预览均从相同编码图集导出。

Pillow 文档基线为 12.3.0，Context7 ID `/python-pillow/pillow/12.3.0`，参考 [图像接口](https://github.com/python-pillow/Pillow/blob/12.3.0/docs/reference/Image.rst)。

客户端程序和已安装的原生文件目录均未修改；美术验收不代表宿主加载故障修复。原有运行时故障结论继续保留。
