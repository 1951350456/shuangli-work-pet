LOCAL FILE INSTALL

霜璃 · 本地版

把已验收的完整精灵图安装到本机宠物目录。

返回动作预览

在 Mac 上使用

  1. 下载并解压完整 GitHub 仓库。
  2. 双击仓库根目录的 安装本地版.command。
  3. 在桌面客户端「设置 → Pets」刷新，选择「霜璃（本地版）」。

安装器只读取仓库中的本地图片，使用 Python 3.9+ 标准库，不联网，也不需要管理员权限。当前云端霜璃会保留。

还需要在客户端确认

本地文件安装完成，不能单独证明永久离线运行。 本次实机测试已经发生自动上云：选择本地版后，账号内出现了对应云端记录。本工具尚未实现当前 Work Pets 的永久离线加载。如果本地条目消失、被合并，或再次等待图片加载，仍需检查应用的迁移和缓存行为。

安装器不会替你选择宠物，也不改写应用程序或隐藏设置。它会逐字节核对已安装的素材，但不会把这些检查当成运行时故障已修复的证据。
